# Zeenat Kureshi — Portfolio & Leadership Portal

Official personal brand and leadership web platform for **Zeenat Kureshi** — Film Producer, GCC–India Trade Commissioner, and National President of All India Jamiatul Quresh Women Cell.

## 🚀 Features

- **Cinematic & Editorial Visual Design**: High-end typography with Cormorant Garamond & Jost, gold gradients, and responsive glassmorphism cards.
- **Bilateral Trade & Investment**: Structured inquiry portal and trade corridor intelligence.
- **Media & Press Hub**: Press clippings, interviews archive, event galleries, and official media kit download.
- **Women Leadership Movement**: National initiatives, event schedules, and volunteer/membership applications.
- **Seamless Responsiveness**: Optimized across mobile phones, tablets, and desktop displays.

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router v7
- **Backend / Database**: Supabase

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Ashutoshkuma8271/newfolio.git
   cd newfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. Start development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
